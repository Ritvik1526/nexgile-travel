# Nexgile-TravAI

Premium AI-powered Travel & Hospitality ecosystem built as a React frontend and Express API. The supplied interface and API source modules are retained and integrated into the application structure.

## Run locally

1. `cd backend && npm install && npm run dev`
2. In a second terminal: `cd frontend && npm install && npm start`
3. Open `http://localhost:3000` and choose any supplied demo account on the login screen.

The API health check is `http://localhost:5000/health`.
